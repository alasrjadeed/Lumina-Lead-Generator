Everything You Need

From scraping to outreach, Lumina handles the entire lead generation pipeline.

Multi-Platform Scraping

Scrape Google Maps, Instagram, Facebook, TikTok, YouTube, Twitter, and more via Apify actors with multi-token fallback.

AI-Powered Enrichment

Auto-classify leads, score quality, and generate personalized outreach using 9 AI providers with smart key rotation.

Bulk Email Outreach

Send personalized emails to hundreds of leads with templates, placeholders, and SMTP integration (Gmail, Yahoo, custom).

WhatsApp Messaging

Bulk send WhatsApp messages, import group members, and generate AI-crafted messages for each lead.

Category Management

Organize leads into categories, set auto-generation rules, and track per-category statistics.

Multi-Key Fallback

Never hit rate limits again. Automatic rotation across multiple API keys for every provider — Apify, OpenAI, DeepSeek, and more.

Built With Modern Tech

Robust, scalable, and easy to customize.

Laravel 9 + PHP 8.3

Enterprise-grade backend with Eloquent ORM, queues, and Blade templating.

SQLite Database

Zero-config database. No server setup needed — just works out of the box.

Bootstrap 5 + jQuery

Responsive admin panel with dark/light theme toggle.

9 AI Providers

Cloudflare, DeepSeek, OpenAI, OpenRouter, GROQ, Gemini, NVIDIA, Mistral, Z.AI — all with multi-key fallback.

Background Jobs

Long-running scraping via exec() with real-time status polling. No queue workers needed.

58 API Key Slots

Store keys for every service via the admin panel. No code changes needed.
